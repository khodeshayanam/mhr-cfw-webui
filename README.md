# MHR-CFW Web UI

رابط گرافیکی محلی برای پروژه [mhr-cfw](https://github.com/denuitt1/mhr-cfw)

> **توجه:** این مخزن یک رابط غیررسمی و کمکی است. هستهٔ رله، GAS و Cloudflare Worker متعلق به **denuitt1** است. اینجا فقط لایهٔ گرافیکی برای ساده‌تر کردن اجرا و پیکربندی اضافه شده است.

| | |
|---|---|
| پروژه اصلی | https://github.com/denuitt1/mhr-cfw |
| این Web UI | https://github.com/khodeshayanam/mhr-cfw-webui |

---

## معرفی

`mhr-cfw` به‌صورت پیش‌فرض از خط فرمان اجرا می‌شود. این Web UI همان منطق را حفظ می‌کند و یک پنل محلی روی `http://127.0.0.1:5050` در اختیار می‌گذارد تا بتوانید:

- تنظیمات (Auth Key، Deployment ID، پورت‌ها و …) را از رابط وارد و ذخیره کنید
- پروکسی را با یک کلیک روشن یا خاموش کنید
- در صورت تمایل، پروکسی سیستم ویندوز را به‌صورت خودکار تنظیم کنید

پیش‌نیاز کارکرد رله، همان استقرار GAS و Worker طبق راهنمای پروژه اصلی است.

---

## پیش‌نیازها

- ویندوز
- Python 3.10 یا بالاتر
- Deployment ID مربوط به Google Apps Script و مقدار `AUTH_KEY` هم‌خوان با `Code.gs`

## نصب

### ۱. پایتون

اگر از قبل نصب نیست، از [python.org](https://www.python.org/downloads/) نسخهٔ مناسب را بگیرید. هنگام نصب گزینهٔ **Add python.exe to PATH** را فعال کنید. سپس در PowerShell:

```powershell
python --version
```

### ۲. دریافت پروژه

```powershell
git clone https://github.com/khodeshayanam/mhr-cfw-webui.git
cd mhr-cfw-webui
```

یا از گیت‌هاب **Code → Download ZIP** بگیرید و پوشه را باز کنید.

### ۳. وابستگی‌ها

```powershell
python -m pip install -r requirements-webui.txt
```

در صورت محدودیت دسترسی به PyPI:

```powershell
python -m pip install -r requirements-webui.txt -i https://mirror-pypi.runflare.com/simple/ --trusted-host mirror-pypi.runflare.com
```

## اجرا

```powershell
python app.py
```

یا `run_webui.bat`. پس از اجرا، پنل در آدرس زیر در دسترس است:

```text
http://127.0.0.1:5050
```

## پیکربندی و استفاده

1. بخش **پیکربندی** را باز کنید.
2. **Auth Key** و **Deployment ID** را وارد کنید (باید با GAS هم‌خوان باشند).
3. در صورت نیاز پورت HTTP (پیش‌فرض `8085`) و SOCKS5 (پیش‌فرض `1080`) را تنظیم کنید.
4. **ذخیره تنظیمات** را بزنید؛ مقادیر در `config.json` ذخیره می‌شوند.
5. در صورت تمایل، گزینهٔ تنظیم خودکار پروکسی ویندوز را فعال کنید.
6. **شروع پروکسی** را بزنید. پس از نصب گواهی، یک‌بار بستن و باز کردن مرورگر توصیه می‌شود.
7. برای توقف، **توقف** را بزنید تا سرویس و در صورت فعال بودن، پروکسی سیستم خاموش شود.

اگر به هر دلیل پروکسی سیستم باقی ماند، می‌توانید `stop_proxy.bat` را اجرا کنید یا از مسیر زیر آن را دستی خاموش کنید:

**Settings → Network & internet → Proxy → Off**

### اشتراک در شبکه محلی

با فعال بودن LAN Sharing، دستگاه‌های دیگر روی همان شبکه می‌توانند از آی‌پی میزبان و پورت‌های بالا استفاده کنند. نصب گواهی CA (پوشهٔ `ca` پس از اولین اجرا) روی کلاینت‌های دیگر معمولاً لازم است.

|--------|------|

| HTTP Proxy | `127.0.0.1:8085` |
| SOCKS5 | `127.0.0.1:1080` |

## عیب‌یابی مختصر

| مشکل | اقدام پیشنهادی |
|------|----------------|
| `python` شناخته نمی‌شود | نصب مجدد با PATH و باز کردن دوبارهٔ ترمینال |
| `No module named flask` | اجرای مجدد `pip install -r requirements-webui.txt` |
| خطای گواهی در مرورگر | بستن کامل مرورگر؛ بررسی نصب CA در لاگ |
| توقف یا قطع اینترنت | `stop_proxy.bat` یا خاموش کردن دستی Proxy ویندوز |
| خطای برخی سایت‌ها | محدودیت سمت GAS/Worker؛ به مستندات پروژه اصلی مراجعه کنید |

## ساختار پروژه

```text
mhr-cfw-webui/
├── app.py                  # سرور Web UI
├── main.py / src/          # هستهٔ پروکسی (برگرفته از پروژه اصلی)
├── config.example.json
├── requirements-webui.txt
├── run_webui.bat
├── stop_proxy.bat
├── templates/ , static/
└── README.md
```

فایل `config.json` پس از ذخیره ساخته می‌شود و نباید در مخزن عمومی قرار گیرد.
